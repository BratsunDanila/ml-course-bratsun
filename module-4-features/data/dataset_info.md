# Паспорт датасета Online Shoppers Purchasing Intention

## 1. Общие сведения
- **Название:** Online Shoppers Purchasing Intention Dataset
- **Источник:** [UCI Machine Learning Repository (ID: 468)](https://archive.ics.uci.edu/dataset/468/online+shoppers+purchasing+intention+dataset) / [Kaggle Dataset](https://www.kaggle.com/datasets/roshansharma/online-shoppers-intention)
- **Авторы:** C. O. Sakar, S. O. Polat, M. Katircioglu, Y. Kastro (2018)
- **Предметная область:** Электронная коммерция (E-commerce), веб-аналитика, прогнозирование конверсии пользовательских сессий в покупку
- **Тип задачи:** Бинарная классификация с выраженным дисбалансом классов
- **Количество сессий (записей):** 12 330
- **Количество колонок:** 18 (17 входных признаков + 1 целевая переменная `Revenue`)
- **Пропущенные значения:** 0 (датасет полностью очищен)

## 2. Структура и распределение целевой переменной
- **Целевая переменная:** `Revenue` (факт совершения покупки / завершения транзакции в рамках пользовательской веб-сессии)
  - `False` (сессия без покупки): 10 422 объекта (84.53%)
  - `True` (сессия с транзакцией): 1 908 объектов (15.47%)
- **Соотношение классов:** ~5.46 : 1 (выраженный дисбаланс, требующий обязательной стратификации при разбиении, балансировки функции потерь `class_weight='balanced'`, использования `scale_pos_weight` в градиентном бустинге, а также оптимизации по метрикам ROC-AUC, PR-AUC, F1-score и Recall вместо тривиального Accuracy).

## 3. Спецификация признаков

### Поведенческие метрики навигации по сайту (6 признаков):
1. `Administrative` (int64): количество посещённых административных страниц (личный кабинет, справка, контакты) за текущую сессию.
2. `Administrative_Duration` (float64): суммарное время нахождения на административных страницах (в секундах).
3. `Informational` (int64): количество посещённых информационных страниц (новости, о компании, условия доставки).
4. `Informational_Duration` (float64): суммарное время нахождения на информационных страницах (в секундах).
5. `ProductRelated` (int64): количество просмотренных товарных страниц (карточки товаров, категории каталога).
6. `ProductRelated_Duration` (float64): суммарное время нахождения на страницах товаров (в секундах).

### Метрики качества веб-сессии от Google Analytics (4 признака):
7. `BounceRates` (float64): показатель отказов — средняя доля пользователей, которые заходят на страницу и сразу покидают ресурс без взаимодействия.
8. `ExitRates` (float64): показатель выходов — отношение количества просмотров страницы, оказавшихся последними в сессии, ко всем просмотрам этой страницы.
9. `PageValues` (float64): средняя ценность страницы — показатель Google Analytics, отражающий вклад страниц в итоговую выручку перед покупкой. Ключевой предиктор конверсии.
10. `SpecialDay` (float64): показатель близости времени сессии к праздничным/специальным датам (День святого Валентина, 8 Марта и др.) со значениями от 0.0 до 1.0 (динамика вероятности совершения заказа до праздника).

### Временные характеристики (2 признака):
11. `Month` (object): календарный месяц сессии (`Feb`, `Mar`, `May`, `June`, `Jul`, `Aug`, `Sep`, `Oct`, `Nov`, `Dec`).
12. `Weekend` (bool): флаг посещения сайта в выходные дни (`True` / `False`).

### Технические и демографические характеристики (4 признака):
13. `OperatingSystems` (int64): закодированный идентификатор операционной системы пользователя (1–8). Категориальный признак.
14. `Browser` (int64): закодированный идентификатор интернет-браузера пользователя (1–13). Категориальный признак.
15. `Region` (int64): закодированный географический регион пользователя (1–9). Категориальный признак.
16. `TrafficType` (int64): источник перехода / канал веб-трафика (1–20). Категориальный признак.

### Тип пользователя (1 признак):
17. `VisitorType` (object): статус пользователя на ресурсе (`Returning_Visitor`, `New_Visitor`, `Other`).

## 4. Конструируемые признаки (Feature Engineering)
- `TotalPages`: суммарное количество всех просмотренных страниц (`Administrative + Informational + ProductRelated`).
- `TotalDuration`: суммарная продолжительность пребывания на сайте за сессию (`Administrative_Duration + Informational_Duration + ProductRelated_Duration`).
- `AvgPageValue`: удельная коммерческая ценность страницы (`PageValues / (TotalPages + 1)`).
- `BounceExitRatio`: соотношение отказов к выходам (`BounceRates / (ExitRates + 0.001)`).
- `ProductPageRatio`: доля товарных страниц в структуре сессии (`ProductRelated / (TotalPages + 1)`).
- `AvgDurationPerPage`: среднее время изучения одной страницы (`TotalDuration / (TotalPages + 1)`).
- `IsNewVisitor`: бинарный признак нового посетителя (`VisitorType == 'New_Visitor'`).
- `IsWeekend`: бинарный индикатор выходного дня (`Weekend.astype(int)`).
- `MonthNum`: порядковый номер календарного месяца (2–12).
- `PageValues_x_TotalDuration`: взаимодействие ценности страниц и логарифма длительности сессии (`PageValues * np.log1p(TotalDuration)`).

# 📊 Описание датасета Titanic (Machine Learning from Disaster)

## 📌 Источник данных
- **Соревнование:** [Kaggle Titanic — Machine Learning from Disaster](https://www.kaggle.com/c/titanic)
- **Категория:** Исторические данные пассажиров лайнера «Титаник» (крушение в ночь с 14 на 15 апреля 1912 года).

## 📐 Структура выборки
- **Обучающая выборка (`train.csv`):** 891 запись, 12 столбцов (включая целевую переменную `Survived`).
- **Тестовая выборка (`test.csv`):** 418 записей, 11 столбцов (целевая переменная скрыта).
- **Всего пассажиров в наборах:** 1309 человек.

## 📋 Описание признаков

| Признак | Тип данных | Описание | Пропуски (train) | Примечание |
|:---|:---|:---|:---:|:---|
| `PassengerId` | `int64` | Идентификатор пассажира | 0 (0.0%) | Уникальный ключ, не используется в обучении |
| `Survived` | `int64` | Целевой признак (0 = погиб, 1 = выжил) | 0 (0.0%) | Бинарный целевой признак |
| `Pclass` | `int64` | Класс билета (1 = 1-й, 2 = 2-й, 3 = 3-й) | 0 (0.0%) | Порядковый признак (прокси социально-экономического статуса) |
| `Name` | `object` | Фамилия, имя и титул пассажира | 0 (0.0%) | Содержит титулы (Mr, Mrs, Miss, Master, Dr и др.) |
| `Sex` | `object` | Пол (`male` / `female`) | 0 (0.0%) | Категориальный признак, кодируется через LabelEncoder |
| `Age` | `float64` | Возраст в годах | 177 (19.87%) | Заполняется групповой медианой по `(Pclass, Sex)` |
| `SibSp` | `int64` | Число братьев/сестёр/супругов на борту | 0 (0.0%) | Используется для создания `Family_Size` и `Is_Alone` |
| `Parch` | `int64` | Число родителей/детей на борту | 0 (0.0%) | Используется для создания `Family_Size` и `Is_Alone` |
| `Ticket` | `object` | Номер билета | 0 (0.0%) | Строковый идентификатор билета |
| `Fare` | `float64` | Тариф / стоимость билета в фунтах | 0 (0.0%) | Непрерывный числовой признак (в test есть 1 пропуск) |
| `Cabin` | `object` | Номер каюты | 687 (77.10%) | Исключается из-за критического количества пропусков |
| `Embarked` | `object` | Порт посадки (`C`, `Q`, `S`) | 2 (0.22%) | Заполняется модой ('S') и кодируется One-Hot Encoding |

## ⚖️ Баланс классов целевой переменной (Survived)
- **Погибло (0):** 549 пассажиров (**61.62%**)
- **Выжило (1):** 342 пассажира (**38.38%**)
- **Базовый дисбаланс:** ~1.6 : 1 (умеренный дисбаланс, требующий анализа не только Accuracy, но и F1, ROC-AUC, Precision, Recall).
